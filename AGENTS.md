# Agent Guidelines - AI-RCOV

## Architectural Decisions & ADRs
This repository uses **Architecture Decision Records (ADR)** formatted according to [MADR](https://github.com/adr/madr) for all significant design, architectural, and data format choices.
- See detailed rule: [.agents/rules/architecture-decisions.md](file:///.agents/rules/architecture-decisions.md)
- All records are located in: [docs/adr/](file:///docs/adr/)
- Template: [docs/adr/template.md](file:///docs/adr/template.md)

When planning or proposing architectural changes (new crates, algorithm design, binary format modifications like `.rcov` / `.rhgt`, concurrency or storage updates), agents must check existing ADRs and propose a new ADR following the MADR template.
